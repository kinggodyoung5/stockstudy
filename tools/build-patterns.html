패턴 생성 경로를 통합했습니다

정합성 검사·규칙 버전·완전한 20봉 집계를 동일하게 적용하려고 브라우저의 별도 생성 코드를 제거했습니다.

Node.js가 설치된 환경에서 저장소 루트를 열고 다음 명령을 실행하세요.

node tools/build-patterns.mjs

원자료는 보존하며 data/patterns의 생성 결과만 교체합니다. 오류 목록과 원본 해시는 data/patterns/_quality.json에 남습니다.

저장된 결과의 생성일을 지정해 재현성을 검사할 수 있습니다.

node tools/build-patterns.mjs --date=2026-09-23 --check
