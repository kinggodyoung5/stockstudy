# 차트 읽는 법 · StockStudy

목표는 **주식 기술적 분석의 기초를 배우고, 차트를 근거와 한계까지 설명하는 것**입니다. 다음 주가를 맞히는 점수와 차트 읽기 능력을 분리합니다. 종목 추천·매매 신호·실시간 시세 서비스가 아닙니다.

## 학습 흐름

가격·봉·시간 → 추세와 지지저항 → 평균과 설정 → 거래량과 변동 폭 → 모멘텀 → 패턴과 맥락 → 종합 설명과 복기.

- **개념 학습**: 33개 레슨. 정의, 앱의 수치 설정, 관찰 근거, 해석 한계를 구분합니다.
- **기초 읽기 연습**: 12개 개념의 수치 변형 문제. 답을 보기 전에 근거·확신도를 기록하고 첫 시도와 재시도를 구분합니다. 서술의 질을 자동 채점하지는 않습니다.
- **실제 차트 입문 6단계**: 가격·시간 → 추세·가격대 → 이동평균 → 거래량·변동 폭 → RSI·MACD → 맥락·종합. 85종목의 480사례로 18주제를 연습합니다. 충족·불충족·확인 대기와 경계·반례를 포함하며 이후 수익률은 선별에 쓰지 않습니다. 도움말·관찰값은 접을 수 있고 마지막 두 주제는 근거도 먼저 기록합니다.
- **실제 차트 비교 연습**: 기초 읽기 연습 안에서 엽니다. 골든·데드크로스, 상승·하락 장악형 4종의 285쌍을 비교합니다. 두 사례의 관찰·해석·반대 증거·무효 조건을 기록한 뒤 20봉 결과와 판정 근거를 공개합니다. 비교용으로 다른 결과를 의도적으로 짝지은 교재이며 시장의 승률 표본이 아닙니다. 최초 근거와 사후 복기를 분리해 최근 30쌍을 이 브라우저에 저장합니다.
- **데이터 뷰어**: 종목·기간·봉 단위·지표를 비교합니다. 지표 계산용 과거 이력과 화면 표시 범위를 분리합니다.
- **과거 통계**: 조건 충족 뒤의 가격 변화를 탐색하는 보조 자료입니다. 매매 전략 검증이나 학습 숙달 점수가 아닙니다.
- **가상 차트**: 무작위 가격에서도 모양이 만들어지는지 관찰합니다. 실제 시장의 모든 성질을 재현하지 않습니다.
- **방향 예측 실험**: 보조 활동입니다. 출현 비율이 다른 세 방향을 고르는 적중률을 숙달 평가로 쓰지 않습니다.
- **시작하기**: 위 순서와 전체 레슨 목록을 안내합니다.

## 정의와 앱 설정 구분

자동 탐지 조건은 기술적 분석의 유일한 정답이 아닙니다. 레슨의 판정 기준과 코드에서 설정을 공개합니다.

- RSI 다이버전스 차이: 5 **포인트** 이상.
- MACD 히스토그램 차이: 두 시점 평균 종가의 0.1% 이상. 0 근처 지표값으로 나누지 않습니다.
- OBV 차이: 첫 극점 다음 봉부터 둘째 극점까지 총거래량의 5% 이상. 누적 시작값을 더해도 같은 구간의 판정이 유지됩니다. 거래량 분모가 0이면 제외합니다.
- 위 다이버전스는 가격 극점에서 지표값을 비교합니다. 지표 자체의 극점을 별도로 찾지 않습니다. 뒤 5봉이 있어야 극점을 확인할 수 있습니다.
- 반전 캔들 10종은 패턴 첫 봉 **전일까지**의 10거래일 ±3%를 검사합니다. 샛별·석별도 포함합니다. 몸통 비교 이력은 패턴 시작 전 20봉입니다.
- 적삼병·흑삼병은 선행 추세를 검사하지 않는 **모양 후보**입니다. 지속·반전은 직접 맥락을 해석해야 합니다.
- 헤드앤숄더와 이중·삼중 패턴은 첫 극점 전일까지 40거래일 ±10%를 검사합니다. 이중·삼중 패턴 깊이는 천장의 최고 고점 또는 바닥의 최저 저점이 분모입니다.
- 최고가·최저가 변화는 모두 **결과 측정 시작일 종가 기준**입니다. 고점 대비 최대 낙폭, 실현 수익, 극값의 발생 순서를 뜻하지 않습니다.

OBV의 누적 계산·절대값보다 방향을 보는 설명은 [Fidelity OBV 안내](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/OBV)를, MACD선과 시그널선의 계산 정의는 [Fidelity MACD 안내](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/macd)를 참고했습니다. **이 출처가 앱의 5%·0.1% 문턱이나 수익성을 검증해 준다는 뜻은 아닙니다.**

## 실행과 검증

빌드 도구 없이 HTML/CSS/JavaScript ES 모듈로 실행하는 정적 앱입니다. 차트 라이브러리는 `vendor/`에 있습니다. `file://` 대신 HTTP로 열어야 합니다.

Windows PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/serve.ps1
```

브라우저에서 `http://localhost:8123` 접속. 서버는 조회 전용이며 브라우저 저장 엔드포인트는 제거했습니다.

Node.js가 설치된 환경에서, 저장 원자료로 57개 결과를 한 번에 재생성합니다:

```powershell
node tools/build-patterns.mjs --date=2026-09-27
node tools/build-patterns.mjs --date=2026-09-27 --check
node tools/build-course.mjs
node tools/build-course.mjs --check
node --test tests/learning.test.mjs tests/pattern-integrity.test.mjs tests/recovery.test.mjs tests/real-study.test.mjs tests/chart-course.test.mjs
node tools/recover-data.mjs --check
```

`--check`는 쓰지 않고 생성 결과와 저장 파일을 바이트 단위로 비교합니다. 날짜를 생략하면 생성 당일 날짜를 사용합니다. 재현 비교 때는 저장된 생성 날짜를 지정하세요. 파일별 임시 파일 후 교체하므로 실행 중 서버를 배포하지 마세요. 전체 디렉터리를 하나의 트랜잭션으로 교체하는 방식은 아닙니다. 로더는 서로 다른 규칙 버전·원자료 해시·생성일을 가진 결과 혼용을 거부합니다.

`tools/collect-recovery.mjs`는 공급자 원문만 보관하고 활성 자료를 변경하지 않습니다. `tools/recover-data.mjs --check`는 네트워크 없이 원본 백업·보존 응답으로 현재 92종목, 인덱스, 복구 보고서를 재현합니다. 현재 실행은 이미 적용됐으므로 `--apply`를 반복 실행하지 마세요. 기존 `tools/fetch-data.ps1`는 복구 이력이 있으면 중단해 실수로 정정 자료를 덮어쓰지 못하게 했습니다. 새 날짜·새 종목 복구는 별도 실행 정책과 검증이 필요합니다.

## 구조와 다음 과제

`src/content/` 레슨·도해·연습 / `src/lib/` 지표·판정·품질검사·통계 / `src/views/` 화면 / `data/stocks/` 원자료 / `data/patterns/` 생성 결과 / `tests/` 회귀 테스트.

현재 앱은 기초 학습의 토대이며, 사용자의 학습 효과나 “마스터”를 검증한 완성 평가 시스템은 아닙니다. 자료 복구로 전체 사례 수는 늘었으므로 새 종목은 아직 추가하지 않았습니다. 입문 실제 차트 480사례와 4종의 반례 비교 285쌍을 제공합니다. 예측 실험도 레슨과 같은 엔진으로 판정합니다. 다음 과제는 서술형 피드백, 처음 보는 종목·시점의 독립 평가, 실제 사례 장기 복습·백업, 남은 32종목과 미국·지수의 자료 검증입니다.
