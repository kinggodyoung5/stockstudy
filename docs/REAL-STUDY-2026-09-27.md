# 실제 차트 비교 연습

차트 기초를 배우는 목표에 맞춰, 결과를 본 뒤 그럴듯하게 설명하는 대신 당시 관찰과 이후 결과를 나눠 기록하는 화면을 추가했다. 메뉴: **기초 읽기 연습 → 실제 차트 비교 연습**, 경로 `#/practice/real`.

## 이번 범위

- 골든크로스 69쌍, 데드크로스 71쌍, 상승 장악형 73쌍, 하락 장악형 72쌍. 합계 285쌍이다. 기존 규칙별 최대 150개 저장 예시를 사용하며, 각 규칙 안에서 중복 사례를 재사용하지 않는다. 다른 규칙 사이에는 겹칠 수 있다.
- 각 쌍은 20봉 종가 변화가 신호 방향과 같은 사례와 반대인 사례다. 보합·미완료·격리 종목은 제외한다. 이는 의도적으로 만든 비교 교재다. 기존 전체 검출·예시 선택·통계에는 영향을 주지 않으며 이 쌍으로 승률을 계산하지 않는다.
- 다른 종목을 우선 짝짓지만, 종목·시점·변동성 등을 일치시킨 실험은 아니다. 관찰 차이로 결과의 원인을 증명할 수 없다. A/B 순서는 성공·실패 라벨이 아니다.

## 학습 흐름

1. 확인일까지 최대 100봉을 표시한다. 지표는 그 이전의 전체 계산 이력을 사용하지만 확인일 뒤의 봉은 전달하지 않는다. 교차 신호는 20/60일선과 거래량, 장악형은 캔들과 거래량을 표시한다.
2. 두 사례에서 각각 관찰 사실·해석과 조건·반대 증거 또는 모르는 점·설명을 바꿀 조건을 적는다. 항목당 8자 이상은 빈 제출 방지용이지 좋은 답 판정 기준이 아니다. 판정 규칙은 미리 읽을 수 있다.
3. 두 사례를 함께 제출하면 최초 근거를 잠그고 확인일 뒤 정확히 20봉과 수치 근거를 공개한다. 결과는 종가 변화 방향이며 실현 수익·손절 여부·분석 능력의 정답이 아니다.
4. 최초 근거를 고쳐 쓰지 않고 사후 복기를 별도 입력한다. 이전 제출을 다시 열면 복습임을 표시한다. 자료 해시와 규칙 버전이 달라지면 기록 키도 달라진다.

제출·복기는 해당 브라우저에 최근 30쌍까지 저장한다. 제출 전 초안은 페이지 이동 시 보존되지 않는다. 저장이 막히면 안내하고 현재 화면에서 계속 사용할 수 있다. 기록 입력은 서버나 Git 저장소로 전송하지 않는다.

## 검증

```powershell
node --test tests/learning.test.mjs tests/pattern-integrity.test.mjs tests/recovery.test.mjs tests/real-study.test.mjs
node tools/recover-data.mjs --check
node tools/build-patterns.mjs --date=2026-09-23 --check
```

42개 테스트 통과. 새 테스트 6개는 비교 표본의 제외·중복 처리, 하락 신호 방향, 확인일 차단, 결과-차트 불일치 거부, 최초 근거 고정, 기록 30쌍 제한, 실제 285쌍의 날짜·20봉 구간을 검사한다. 자료 복구와 패턴 스냅샷 재현은 모두 일치하며 이 작업에서 원자료나 탐지 정책을 다시 변경하지 않았다.

Browser 스킬로 빈 제출 차단, 두 사례 동시 공개, 읽기 전용 최초 근거, 복기 저장과 새로고침 후 복원, 다음 쌍의 비공개 초기화를 확인했다. 1280/768/375px에서 안내·차트·입력 영역의 가로 넘침이 없었고 브라우저 오류 로그도 없었다. 테스트용 입력은 로컬 브라우저에만 남으며 커밋에 포함하지 않는다.

## 후속 작업

이 기능은 비교·복기 교재이지 학습 효과를 검증한 평가 체계가 아니다. 패턴 탐지 자체를 맞히는 문제, 문턱 근처 경계·비신호 사례, 결과 정보를 전혀 이용하지 않고 뽑은 별도의 전이 평가, 장기 복습 일정은 아직 없다. 조건을 충족하지 않은 사례까지 포함해 스스로 구별하는 능력을 다음 단계에서 다룬다. 서술 평가를 자동화하려면 관찰 사실·개념 오류·불확실성의 채점 기준부터 별도 설계해야 한다.
