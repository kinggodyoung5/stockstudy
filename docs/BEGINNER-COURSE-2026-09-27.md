# 입문 학습 재구성 — 로드맵 1~3 완료

목표는 기술적 분석을 처음 접하는 사람이 실제 차트의 관찰 사실, 해석, 한계를 구분하는 것이다. 적중률이나 수익성을 학습 성적으로 삼지 않는다.

## 1. 정의·설명·판정 통합

- 보조 예측 퀴즈의 별도 간이 계산을 제거했다. 레슨과 같은 엔진의 12개 주요 규칙을 사용하고, 마지막 관찰일까지 최근 10거래일에 확인 완료된 조건만 표시한다. 교차 유지 확인 전의 후보는 완료 신호로 세지 않는다.
- 거래량 3배/2배, 이격도 92/90의 불일치를 제거했다. 이격도 문턱을 처음 넘는 사건과 이미 밖에 있는 상태, 재발 간격도 구별해 설명한다.
- RSI의 높은/낮은 상태를 자동으로 이후 하락/상승 정답으로 연결하지 않는다. 체크리스트는 결과를 본 뒤 하는 복습임을 명시한다.
- 가격·비율·포인트·거래량·봉 수·횟수의 명시 단위를 모든 숫자형 탐지 근거에 붙였다. 미등록 라벨은 생성 시 실패하며, 화면은 알 수 없는 단위를 통화로 추측하지 않는다. 거래량의 마지막 값이 가격 눈금처럼 보이지 않게 차트 표시도 정리했다.
- 교차·거래량 조건은 엔진과 입문 교재가 공통 함수를 사용한다. 장악형도 기존 캔들 판정 함수를 사용한다.
- 설정값의 효과를 과장한 설명, 거래량에서 참여자 의도를 확정하는 설명, 현재 자료와 연결되지 않은 과거 실험 수치를 수정했다. 표준편차·MACD 교차 방향을 명확히 하고, 연도별 구성 도해는 실제 통계가 아니라고 표시했다.
- 규칙 버전은 `2026-09-27.v4`. 57개 결과를 재생성했다. 이전 커밋과 비교한 검출 사례·결과 변화는 0개 규칙이며 요약 통계도 동일하다. 총 검출 83,356건, 20봉 완료 82,695건, 학습 가능 85종목 유지. 원자료 복구 파일은 변경하지 않았다.

## 2. 충족·불충족·확인 대기 식별

`#/practice/chart`에서 실제 가격을 사용한다.

- 상향/하향 교차 각각 조건 충족·불충족·5거래일 확인 대기: 6상태, 48사례.
- 거래량 급증: 충족·2배 직전·가격 변화 부족·직전 반복 후보: 4상태, 32사례.
- 감싸는 몸통: 충족·몸통 크기 부족·선행 하락 미충족: 3상태, 24사례.

조건을 먼저 공개하고 학생이 직접 비교하게 한다. 기다려야 하는 경우와 이미 조건이 깨진 경우를 다르게 채점한다. 결과가 오르거나 내려야 패턴이 된다는 식으로 판정하지 않는다.

## 3. 기초 전 범위 실제 차트 과정

| 단계 | 실제 차트에서 할 일 |
| --- | --- |
| 가격·시간 | 봉의 색과 전일 등락, 꼬리, 완료된 주의 일봉/주봉 비교 |
| 추세·가격대 | 확인된 고점·저점, 직전 20봉 최고가와 종가/장중 돌파 구별 |
| 이동평균 | 위치, 5거래일 기울기, 5/20과 20/60 조합, 교차 확인 조건 |
| 거래량·변동 폭 | 직전 평균과 거래량 비교, 급증 경계 사례, ATR%, 밴드 안팎 |
| 모멘텀 | RSI의 상태, MACD선·시그널선·히스토그램의 서로 다른 관계 |
| 맥락·종합 | 몸통과 선행 추세, 엇갈리는 관찰 요약, 해석을 바꿀 조건과 근거 기록 |

6단계·18주제·60개 관찰 상태·480사례, 실제 사용 85종목. 상태마다 서로 다른 8종목을 골랐다. 일반 관찰은 17봉 간격 후보, 드문 교차·급증·장악형은 매 봉 후보를 검사한다. 종목별 후보를 해시 순서로 결정적으로 선택한다. 이후 결과는 선별 입력에 없다. 상태를 의도적으로 고르게 구성했으므로 발생 비율 추정용 자료는 아니다.

앞서 만든 285쌍 비교 연습은 그대로 별도 제공한다. **그 화면은 반대 결과의 사례를 의도적으로 짝짓는 교재**다. 새 480사례 과정의 결과 독립 선별과 혼동하지 않는다.

입문 단계는 20봉으로 확대해 봉을 보고 숫자 도움을 함께 쓴다. 뒤 단계는 관찰값 도움을 기본으로 접고 직접 읽게 하되 언제든 열 수 있다. 주봉은 진행 중일 수 있는 마지막 주를 제외한다. 추세 연습의 고저점은 이 교재의 좌우 3봉 기준이며 레슨의 자동 지지·저항/다이버전스 5봉 기준과 구분한다.

선택지는 순서를 바꾸고 처음 제출한 답은 잠근다. 종합 두 주제는 근거를 먼저 적어야 해설을 연다. 기록은 브라우저·교재 버전·원자료 버전별로 분리하며 동기화하지 않는다. 기존 기록을 삭제하지 않는다. 글자 수 검사는 제출 여부 확인일 뿐 글의 질 평가가 아니다.

## 범위 밖으로 남긴 것

로드맵 4~6의 서술형 근거 평가, 처음 보는 종목·시기의 독립 숙달 시험, 실제 사례 기반 장기 복습·백업은 아직 하지 않았다. 480개 문제를 풀었다고 기초 마스터나 투자 수익 능력을 인증하지 않는다. 학습 효과는 실제 초보 사용자 관찰과 지연 평가로 추가 확인해야 한다. 미국 자료·지수의 교차 대조와 남은 32종목 복구도 별도 과제다.
