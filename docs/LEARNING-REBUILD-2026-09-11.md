## 목표와 범위

목표는 기술적 분석의 기초를 이해하고 새 차트를 근거와 한계까지 설명하는 능력이다. 다음 20일 방향 적중률이나 단순 과거 집계를 숙달 점수로 쓰지 않는다.

이번 단위는 **차트 표시 정확성, 잘못된 설명, 입문 학습 흐름, 기초 읽기 연습과 회귀 테스트**까지다. 탐지 엔진과 원자료는 이번에 교체하지 않았다. 알려진 문제가 모두 해결되었다는 뜻이 아니다.

## 구현

- 차트의 표시 구간과 계산 이력을 분리. 이동평균·볼린저·일목·RSI·MACD 등은 표시 시작일 이전 데이터까지 계산하고, 표시 종료일 이후는 차단한다. 초기 결측 날짜도 유지해 보조지표와 시간축을 맞춘다.
- 학습 사례·뷰어·방향 예측 실험에 같은 계산 이력 정책 적용. MACD 다이버전스에는 MACD 패널을 표시한다.
- 사례를 넘길 때 다른 종목까지 순환하고, 폐기된 차트와 동기화 이벤트를 정리한다. 비동기 페이지 렌더가 새 화면을 덮어쓰지 않도록 페이지 DOM을 분리하고 뷰어·퀴즈의 오래된 요청을 무시한다.
- 뷰어는 기준일 뒤 일봉을 제거한 뒤 주봉·월봉을 합친다. 3개월 월봉이 최소 20개월로 확대되던 문제 수정. 기간 숫자가 선택한 봉 단위임을 안내한다.
- 상대강도는 가격과 다른 패널에 표시. 코스닥 종목은 코스닥 지수를 기본 비교 대상으로 사용한다. 매물대는 실제 가격별 체결량이 아닌 균등 배분 근사임을 밝힌다.
- 뷰어·가상 차트의 최대 낙폭은 종가 고점에서 이후 종가 저점으로 계산. 사례의 최고가·최저가 변화는 기준 종가 대비 극값이며 시간 순서·실현 수익·최대 낙폭이 아님을 명시한다.
- 원자료를 임의 보정하지 않는다. 오류 봉이 있는 학습 사례 차트는 보류하고, 뷰어에는 원자료 오류 수를 안내한다. 원자료 오류가 없는 구간도 그 이전 오류의 영향을 받을 수 있으며 이를 완전 정정한 것은 아니다.
- 신규 레슨: 가격·봉·시간, 추세와 횡보, 종합 분석 순서. 총 33레슨. 홈은 7단계 입문 과정 중심으로 재구성.
- 기초 읽기 연습: 12개 개념, 일부 수치 변형, 선택지 순서 변경, 제출 전 근거·확신 기록, 해설, 첫 시도 기록, 재시도, 1/3/7일 복습 안내. 기초 문제는 구성 예제이며 실제 시장 검증 표본이 아니다. 저장은 브라우저 로컬이며 실패 시 안내한다.
- 서술 근거를 자동 채점했다고 주장하지 않는다. 학습자가 해설과 대조하며, 실제 차트로 옮겨가는 관찰·해석·반대 증거·무효 조건 과제를 제공한다.
- 기존 퀴즈는 ‘방향 예측 실험’으로 분리. 기초 숙달 평가가 아니라 보조 활동이며 간이 체크리스트와 레슨 규칙이 아직 다르다는 경고를 표시한다.
- RSI 계산 설명, 거래량과 참여자 구분, OBV 해석, 스퀴즈, 52주/사상 최고가, 장대봉의 장중 경로, 빈도와 효과, 설정 민감성과 유의성 문구 수정. 관련 거래량·신고가·기준선 도해 문구도 수정했다.
- 거래량 2배·절대 등락 2%, 이격도 110/90, 지지·저항 3회, 삼중 패턴 최고값 대비 5% 등 본문과 엔진 조건을 맞췄다. 재계산되지 않아 현재 데이터와 맞지 않는 골든크로스 조합 비교표는 제거했다. 기존 내용은 Git 기준 커밋에서 복원할 수 있다.

## 다음 단위 — 중요도 순

1. **원자료 정합성**: 147개 오류 봉의 원인과 분할·배당 조정 정책 확인. 출처와 수정 이력을 남기고 재수집/제외 정책을 결정한다. 임의로 high/low를 넓혀 해결하지 않는다. 거래정지·거래량 0과 오류를 구분한다.
2. **탐지 정의 일관성**: OBV는 누적 시작값에 불변인 정규화, MACD는 0 근처 폭주를 막는 정규화. 임계값은 새 앱 설정임을 밝히고 경계 사례 테스트를 붙인다. OBV ‘증가’와 ‘하락일 거래량 감소’를 동일시하지 않는다.
3. **패턴 맥락**: 반전 패턴의 선행 추세를 패턴 시작 전까지만 측정. 기존 추세 검사도 끝 봉이 섞이는지 확인한다. 샛별·석별·헤드앤숄더의 선행 추세와 적삼병·흑삼병의 ‘모양 후보’/‘반전’/‘지속’ 용어를 정리한다.
4. **전체 재생성**: 위 변경 뒤 탐지 결과와 20거래일 완전 관측 집계, 기준선, 세부 분류, 문서·레슨 숫자를 한 버전으로 재생성한다. 출처 시점·규칙 버전·표본 포함 기준을 저장한다. 20일 미만 혼입은 일관성 문제지만 이전 감사에서 승률 변화가 0.5%p 이상인 규칙은 57개 중 2개였다. 데이터·표시 문제보다 과장해 우선하지 않는다.
5. **구식 예측 실험**: 간이 판정을 엔진과 통합하거나 별도 명칭으로 명확히 분리. 결과 공개 전 근거를 기록하고 실제 출제 분포 기준선과 비교한다. 33.3% 무작위 기준이 원래 구현돼 있었다고 주장하지 않는다.
6. **학습 전이 확장**: 실제 과거 차트의 미래 가림, 사람이 검토한 모범 관찰·반례·불명확 사례, 학습 요소별 문제 연결, 종목·시기를 분리한 종합 평가. 현재 12문제를 모두 맞힌 것을 기초 마스터 인증으로 사용하지 않는다.
7. **차트 세부 표현**: 일목 미래 26봉 투영·구름 면 채움, 장기 캔들 패턴 경계값, 남은 도해·본문 전체 교차 검토, 더 폭넓은 비동기 전환/저장 실패 UI 회귀 테스트.

## 앞선 검토서의 정정

- `outcomeAt`의 maxUpPct/maxDownPct는 둘 다 진입/확인일 종가 기준이다. 고가 대비 저가 낙폭으로 설명하면 잘못이다. 뷰어·가상 차트의 별도 MDD 계산과 구분한다.
- 캔들 선행 추세는 모두 빠진 것이 아니라 규칙별 구현이 일관되지 않다. 검사 유무뿐 아니라 검사 기준 시점도 확인해야 한다.
- 52주 신고가 레슨은 모멘텀 관점을 소개한 문맥이었다. 앱의 단정으로 몰아붙이는 대신 관점 자체의 부정확한 설명을 보완한다.
- 33.3% 비교는 기존 구현 결함이 아니라 향후 평가 설계에 대한 조언이었다.
- 정배열도 골든크로스·구름대와 같은 표시 이력 결함이었으며 이번 테스트에 포함했다.
